GOOD TO KNOW

Frequently asked questions

Is SheetPDF free to use?

Yes, the tools in this starter version are free to use. File size and browser memory can limit very large documents.

Are my files uploaded?

The file-processing tools in this version run in your browser. The health endpoint does not accept or store files. External library scripts are loaded from CDNs.

Can scanned PDFs be converted to editable Excel?

This first version extracts selectable PDF text. Scanned pages require OCR, and complex tables may need manual cleanup. OCR is planned as a separate enhancement.

Will the converted spreadsheet look exactly like the PDF?

Not always. PDF-to-Excel conversion prioritizes extracting text into cells. Complex layouts, columns and images may not map perfectly.
